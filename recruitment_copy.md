# The Idea: What We're Building

**Configless full-stack OSS.**
Devs write pure code (tRPC routes, Prisma models); we abstract the configs. No boilerplate—just power.

**Recruit Role: Flesh out the ingestion logic.**
We need builders to help design the runtime that ingests `schema.prisma` and auto-extends it with auth tables and 2FA logic.

```typescript
// imagined-root.ts
// Help us make this real:
import { core } from "@factiii/core";

export const runtime = core.ingest({
  schema: "./prisma/schema.prisma",
  auth: { strategy: "jwt", mfa: true }, // <--- You build this logic!
});
```
