# Pre-Presentation Checklist

Use this checklist before sharing the pitch deck with investors.

## ✅ Technical Setup

- [ ] Development server starts without errors (`npm run dev`)
- [ ] Build completes successfully (`npm run build`)
- [ ] Login page loads at `/p/zfm845in/login`
- [ ] Password authentication works (`factiii2025secure`)
- [ ] Cookie persists after login (can navigate away and back)
- [ ] All 7 sections render correctly
- [ ] Animations trigger on scroll
- [ ] Responsive design works on mobile/tablet
- [ ] No console errors in browser DevTools

## ✅ Content Review

### Hero Section
- [ ] Key metrics are accurate ($8.2B TAM, 20M+ devs, 30% time)
- [ ] Logo displays correctly
- [ ] Gradient text renders properly

### Problem Section
- [ ] All 4 pain points are clear and compelling
- [ ] Statistics are believable and sourced
- [ ] Color coding (red) emphasizes urgency

### Solution Section
- [ ] 5-step adapter flow is easy to understand
- [ ] "Viper for Node.js" positioning is clear
- [ ] Features highlight unique value props

### Competitor Table
- [ ] All 11 competitors are listed correctly
- [ ] Comparison dimensions are accurate
- [ ] factiii.io advantages are highlighted
- [ ] Table scrolls horizontally on mobile
- [ ] Check marks and X's render correctly

### Market Analysis
- [ ] TAM/SAM/SOM numbers are defensible
- [ ] Target audience segments make sense
- [ ] Market trends are current and relevant

### Strategy Section
- [ ] Go-to-market strategy is clear
- [ ] Revenue model pricing is realistic
- [ ] Competitive advantages are compelling

### Roadmap
- [ ] Phase timelines are achievable
- [ ] Metrics (users, revenue) are realistic
- [ ] Progression makes logical sense
- [ ] "Cloudless vision" is clearly explained

## ✅ Presentation Prep

- [ ] Test on actual presentation device (laptop/tablet)
- [ ] Check internet connection stability
- [ ] Bookmark the URL for quick access
- [ ] Have password ready (don't fumble at login)
- [ ] Test screen sharing if presenting remotely
- [ ] Adjust screen brightness for visibility
- [ ] Close unnecessary browser tabs
- [ ] Disable notifications during presentation
- [ ] Have backup plan (PDF export or screenshots)

## ✅ Deployment (if sharing URL)

### Vercel Setup
- [ ] Repository pushed to GitHub
- [ ] Vercel project created and connected
- [ ] Environment variables set:
  - [ ] `PITCH_PASSWORD` (secure password)
  - [ ] `PITCH_SLUG` (keep as `zfm845in` or change)
- [ ] Production build succeeds
- [ ] Test authentication on production URL
- [ ] Verify all sections load correctly
- [ ] Check mobile responsiveness on real device

### Security
- [ ] Password is strong and unique for production
- [ ] URL slug is communicated securely (not in email subject)
- [ ] Consider time-limiting access (manual for now)
- [ ] Monitor access if analytics are enabled
